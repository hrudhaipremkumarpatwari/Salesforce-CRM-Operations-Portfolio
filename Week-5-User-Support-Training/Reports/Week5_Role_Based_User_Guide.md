# Week 5 — Role-Based Salesforce User Support Guide

> Educational training artifact. Navigation and examples are illustrative; they are not screenshots or evidence from a private/live Salesforce org.

## Sales user — lead update
1. Open the Leads workspace and select the assigned record.
2. Verify name, company, contact details, source, region, and qualification notes.
3. Update only fields supported by known information.
4. Save and review the record for completeness.
5. Escalate suspected duplicates rather than creating another record.

## Service user — case handling
1. Open the assigned case and review status, priority, customer context, and recent activity.
2. Record a concise troubleshooting note.
3. Update status only when the process condition is met.
4. Escalate critical or unresolved cases using the defined support path.
5. Do not paste passwords, secrets, or unnecessary personal data into case notes.

## Operations user — data-quality check
Review records with missing routing fields, invalid values, possible duplicates, or stale ownership. Correct only verified information and document exceptions that require a business owner.

## Administrator/support triage
Check whether the issue is user-specific or widespread; capture object, record type, error text, time, and reproduction steps; review permissions/configuration before changing data; test fixes in an appropriate non-production environment; communicate resolution and prevention guidance.

## Practice exercise
Using fictional records, complete one lead update, one case escalation, one duplicate-identification exercise, and one report-filter exercise. Record expected versus observed training results.
