# Week 3 — Salesforce Integration Analysis and Planning

## Project overview

This project proposes a target-state integration among Salesforce CRM, an ERP represented by SAP S/4HANA, and a marketing automation platform. It includes data ownership, candidate flows, field mapping, risk controls, implementation phases, acceptance tests, and monitoring guidance.

> **Training and simulation scope:** Cedarline Office Products is fictional. System landscape, message examples, mappings, and service targets are simulated design assumptions. No live Salesforce org, ERP, marketing platform, API credentials, or customer data were accessed; no integration was configured, tested, or deployed.

## Accuracy boundary

The current integration inventory is unknown because no actual org or system evidence was supplied. All latency objectives are proposed planning targets, not measured outcomes or guarantees. Treat the package as a functional planning exercise and validate requirements, security, API capacity, consent ownership, and service objectives with system owners before implementation.
